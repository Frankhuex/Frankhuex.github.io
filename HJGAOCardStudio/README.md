# 卡牌工坊

纯 HTML、CSS、JavaScript，无依赖、无构建步骤。通过静态服务器打开 `index.html`。

- 按类型首次出现顺序导入，保留同类型子序列顺序。
- 默认未分类使用空字符串，页面常驻灰色标记，导出省略 type。字面名称“未分类”属于普通类型。
- 空类型可创建、排序、改名、删除；默认分组不可改名或删除。空类型只保存在本地编辑会话中。
- 类型与类内卡牌可拖动排序，落点显示插入线；菜单提供上下移动。
- 选中卡牌后，底部显示批量移动工具栏。
- 删除、移动、排序、导入、清空、字段编辑支持最多 50 步会话内撤销。输入框内保留浏览器原生文本撤销。
- JSON 导出前验证重复名称、空名称和非负整数数量。
- AI 提示词可附上当前有效卡组。
- 自动保存使用独立 localStorage 键，不读取或覆盖旧编辑器会话。刷新后撤销历史清空，卡牌数据与空类型保留。

运行数据规则测试：`node HJGAOCardStudio/tests/model.test.cjs`。
