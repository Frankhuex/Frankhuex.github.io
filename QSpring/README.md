# Q 弹工坊

纯 HTML、CSS、JavaScript 的静态图片 Q 弹 GIF 生成器。直接打开 `index.html`，或通过静态服务器访问 `/QSpring/`。无构建步骤、第三方依赖和外部请求。

支持图片选择与拖放、30 种经典缓动组合与线性曲线、倍率/周期/方向/回弹强度/振荡次数调节、播放暂停与时间轴拖动，以及透明或纯色背景的 GIF 生成、取消和下载。GIF 输入暂不支持。

## 几何与时间

倍率 s 在 [1/k, k] 内变化，绘制宽高为 W*s、H/s，面积保持 W*H。以画布底边为锚点、水平居中绘制，位置为 ((canvasWidth-W*s)/2, canvasHeight-H/s)。原图尺寸模式下画布为 ceil(kW) × ceil(kH)；其他尺寸选项等比例缩小或放大整体输出。透明留白按原图的一部分处理。

一个周期包含正向和反向运动。Back、Elastic 按采样得到的最小最大值归一化并限制在 [0,1]，保留回弹形态，避免突破倍率边界。归一化后的端点可能处于倍率范围内部。导出按 GIF 的 10 ms 时间单位分配帧延时，完整周期时长保持一致，不重复写入末尾起始帧。

## 编码

`gif.js` 在 Web Worker 内编码 GIF89a，采用逐帧自适应调色板（最多 255 色及一个透明色）与蛇形误差扩散、LZW 压缩、逐帧背景清除以及无限循环。Alpha 小于 128 视为透明。GIF 的色彩精度和半透明表现与原图存在差异。调色板通过像素颜色统计和加权中位切分生成，保留照片中的主要色彩与渐变。

单边导出上限 4096 像素，总帧像素上限 6000 万；超过时可降低画布尺寸、帧率或周期。静态 WebP/APNG 等被浏览器解码后只截取一个画面。

运行核心验证：`node QSpring/test.cjs`。测试覆盖所有曲线的倍率边界、面积守恒、底边位置、循环接缝与帧时长，并生成 GIF 供安装了 FFmpeg 的环境解码验证。
